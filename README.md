# Codex International Kit

Base curada para desenvolvimento assistido por Codex com foco em **segurança, design, revisão e entrega profissional**.

## O que este kit contém

- Agente de revisão: `agents/code-reviewer.md`
- Skills de design e execução:
  - `skills/brainstorming/`
  - `skills/writing-plans/`
  - `skills/executing-plans/`
  - `skills/subagent-driven-development/`
- Skills de qualidade:
  - `skills/test-driven-development/`
  - `skills/systematic-debugging/`
  - `skills/verification-before-completion/`
  - `skills/requesting-code-review/`
  - `skills/receiving-code-review/`
- Skills de operação de branch:
  - `skills/using-git-worktrees/`
  - `skills/finishing-a-development-branch/`
- Guias e templates:
  - `docs/codex-internacional-setup.md`
  - `docs/setup-local-codex.md`
  - `docs/vscode-codex-replicavel.md`
  - `docs/acompanhamento-macos-passo-a-passo.md`
  - `templates/design-template.md`
  - `templates/implementation-plan-template.md`
  - `templates/review-checklist.md`

## Como operar no dia a dia

1. Defina o problema e limite o escopo.
2. Use `brainstorming` para fechar design.
3. Use `writing-plans` para quebrar em tarefas executáveis.
4. Execute com `executing-plans` ou `subagent-driven-development`.
5. Faça review com `requesting-code-review` + `agents/code-reviewer.md`.
6. Valide com `verification-before-completion` e finalize branch.

## Padrão mínimo de aceite

- Design aprovado
- Plano com tarefas atômicas
- Evidência de validação técnica
- Review sem pendências críticas
- Registro objetivo do que mudou e por quê
