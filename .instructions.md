# 🎯 Instruções do Projeto

Este é um **Codex Kit** — sistema operacional profissional para trabalhar com agentes de IA.

## ✨ O que é este projeto?

- **Kit mestre de skills**: Base operacional que você replica em outros projetos
- **Não é um produto final**: É uma estrutura pronta para usar e customizar
- **100% replicável**: Pode ser clonado em qualquer novo projeto
- **Baseado em Superpowers**: Adaptado para seu fluxo local

## 🗺️ Você deve saber

### Dois sistemas importantes

| Sistema | Arquivo | Propósito |
|---------|---------|----------|
| **Seu sistema local** | `/AGENTS.md` | Define qual skill usar em cada situação |
| **Referência externa** | `/.codex-kit/docs/SUPERPOWERS-REFERENCE.md` | Filosofia de design (leitura opcional) |

### Nunca misture nomenclaturas

❌ **Não faça:** "Use `superpowers:writing-skills`"  
✅ **Sempre use:** "Use `.codex-kit/skills/writing-plans/`"

### Saída de código direto

- Quando pedir implementação, solicite **apenas código**.
- Use: `Only output code. Do not add comments or explanations.`
- Não adicione anotações ou explicações a menos que você peça.

### Documentação Consolidada

Toda a documentação está em **`/.codex-kit/docs/`**:
- **INDEX.md** — Navegação completa (comece aqui!)
- **setup/** — Guias de configuração (macOS, local, VSCode)
- **guides/** — Guias operacionais (repositórios internacionais)
## 📋 Regras obrigatórias (gates)

1. Não implementar sem design aprovado
2. Não iniciar sem plano executável por tarefas atômicas
3. Não concluir sem validação técnica registrada
4. Não concluir sem code review
5. Não marcar "done" sem verificação final

## 🚀 Como começa

1. **Leia primeiro:** `/AGENTS.md`
2. **Depois leia:** `/.codex-kit/docs/00-GETTING-STARTED.md`
3. **Customize:** Edite AGENTS.md com seus skills

## ⚡ Quick reference

- Ideia vaga / confusa → `.codex-kit/skills/brainstorming/`
- Design pronto / precisa planejar → `.codex-kit/skills/writing-plans/`
