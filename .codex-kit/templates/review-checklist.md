# Review Checklist

## Escopo e design
- [ ] Mudança bate com o design aprovado
- [ ] Sem feature creep

## Qualidade técnica
- [ ] Código legível e simples
- [ ] Sem duplicação desnecessária
- [ ] Tratamento de erros adequado

## Segurança
- [ ] Inputs validados
- [ ] Sem segredos hardcoded
- [ ] Permissões e acesso mínimos

## Verificação
- [ ] Testes relevantes executados
- [ ] Evidência anexada (comandos/saída)
- [ ] Sem regressões conhecidas
