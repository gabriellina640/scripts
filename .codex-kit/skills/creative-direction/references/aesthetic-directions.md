# Aesthetic Directions Reference

Use this file only when `creative-direction` needs stronger visual alternatives.

## Direction Families

### Editorial Object-Led
- Best for: portfolios, brands, venues, products, restaurants, artists.
- Core move: real object/person/place dominates first viewport.
- Avoid: generic split hero and floating cards.

### Cinematic Immersive
- Best for: games, entertainment, events, sports, culture, travel.
- Core move: full-bleed scene, movement, atmosphere tied to actual subject.
- Avoid: dark blurry stock background with vague copy.

### Operational Precision
- Best for: SaaS, CRM, finance, admin tools, logistics, dashboards.
- Core move: dense but calm workspace, sharp hierarchy, efficient controls.
- Avoid: marketing hero pretending to be an app.

### Crafted Boutique
- Best for: premium local businesses, craft products, hospitality.
- Core move: tactile typography, material texture, object detail, restrained motion.
- Avoid: beige sameness and fake luxury minimalism.

### Playful System
- Best for: education, games, creator tools, youth products.
- Core move: responsive interactions, expressive states, distinctive controls.
- Avoid: childish decoration disconnected from workflow.

### Technical Instrument
- Best for: developer tools, AI tools, analytics, infrastructure.
- Core move: readable code/data artifacts, precise panels, visible system behavior.
- Avoid: neon cyberpunk cliche unless the product truly calls for it.

## Strong Concept Formula

Use:

`[domain-specific subject] + [composition posture] + [interaction personality]`

Examples:

- "Match-day control room with live tournament tension."
- "Handmade catalog where every product feels inspected, not listed."
- "Analyst cockpit with calm precision and zero decorative noise."

Weak concepts:

- "Modern and clean."
- "Premium SaaS."
- "Beautiful dashboard."
- "Minimal but elegant."
