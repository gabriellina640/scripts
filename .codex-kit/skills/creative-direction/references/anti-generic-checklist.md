# Anti-Generic Checklist

Use before approving a creative direction or handing off to `interface-craft`.

## Must Pass

- [ ] The first viewport clearly signals the product, brand, person, place, game, or workflow.
- [ ] The concept has a visual thesis stronger than "modern", "clean", or "premium".
- [ ] The layout is not just hero + cards + feature grid.
- [ ] The palette has roles and contrast, not one hue repeated.
- [ ] Typography has a reason tied to the product tone.
- [ ] Assets are real, generated for the subject, or intentionally product-specific.
- [ ] Motion describes state, navigation, cause/effect, or personality.
- [ ] Empty/loading/error states are considered.
- [ ] Mobile is designed intentionally.
- [ ] The interface would still feel specific if the marketing copy were removed.

## Immediate Rejection

- Generic SaaS gradient hero.
- Floating cards as the main visual idea.
- Decorative blobs/orbs.
- Stock imagery that hides the subject.
- Dashboard without domain-specific data/state.
- Color palette chosen only because it looks trendy.
- No asset strategy.
- No explanation of why this belongs to this product.
