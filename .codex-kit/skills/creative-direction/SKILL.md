# Creative Direction

Use this before `interface-craft` for any visible product experience that should not look generic.

## Hard Gate

Do not implement UI until the creative direction is approved.

## Inputs

- Product type and audience
- Core emotional impression
- Brand/product/person/place being represented
- Existing design system or constraints
- Competitors or references, if any

## Process

1. Inspect current UI, assets, brand language, and constraints.
2. Define the experience goal in one sentence: what the user should feel and understand in the first 5 seconds.
3. Propose 2-3 distinct directions with tradeoffs:
   - one recommended direction
   - one safer direction
   - one bolder direction
4. For the chosen direction, define:
   - visual thesis
   - palette with roles, not just colors
   - typography role and rhythm
   - imagery or asset strategy
   - motion and interaction personality
   - density and layout posture
   - what must be avoided
5. Get user approval before UI implementation.

## Anti-Generic Rules

- No one-note palettes.
- No decorative gradient blobs as the main idea.
- No generic SaaS hero with cards floating around a headline.
- No fake screenshots when real product state should be shown.
- No brand expressed only through nav text.
- No UI that could belong to any unrelated startup after swapping the logo.

## Output

Create a creative direction brief:

- Direction name
- Visual thesis
- Audience fit
- Palette and typography
- Asset plan
- Motion/interactions
- Layout principles
- Specific anti-patterns
- Acceptance criteria for visual QA
