# UI/UX Delivery Checklist

- [ ] Objetivo da tela está explícito
- [ ] Hierarquia visual clara
- [ ] CTA principal visível acima da dobra (quando aplicável)
- [ ] Contraste mínimo WCAG AA
- [ ] Estados hover/focus/disabled definidos
- [ ] Navegação por teclado funcional
- [ ] Breakpoints validados (375 / 768 / 1024 / 1440)
- [ ] Microcopy claro e sem ambiguidade
- [ ] Sem animações excessivas (respeita prefers-reduced-motion)
