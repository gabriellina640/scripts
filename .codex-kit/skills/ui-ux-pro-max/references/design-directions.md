# Design Directions (Base)

## Direction A: Clean Professional
- Typography: sans-serif moderna
- Spacing: 8pt grid
- Border radius: 10–14px
- Elevation: sombras leves
- Uso: B2B, SaaS, produto técnico

## Direction B: Premium Soft
- Tipografia com contraste (serif + sans)
- Paleta suave com CTA destacado
- Animação curta (150–250ms)
- Uso: wellness, lifestyle, premium services
